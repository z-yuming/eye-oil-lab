# 实验工厂 · 眼油产品开发平台

这是一个面向眼部护理产品开发的本地工作台，当前包含：

- 产品机会快跑：市场、竞品、用户证据与产品路径评审
- 项目记录：按项目保存来源机会、产品路径、阶段进度和决策快照
- 项目执行：八个可并行进入的产品研发工作流
- 供应商匹配：包材、内料、包装、代加工和检测供应商匹配
- Excel 供应商库导入与项目内自动保存

## 本地运行

```bash
pnpm install
pnpm run dev
```

打开 `http://127.0.0.1:5173/`。

## 环境变量

复制 `.env.example` 为 `.env.local`，按需填写 AI 顾问所需的 API 配置。`.env.local` 不会被提交到仓库。
